# Shopify App Listing Draft

## Recommended App Name

AdTrace Markets & Attribution

## Alternate Names

- AdTrace Conversion Control
- AdTrace Multi-Market Tracking
- AdTrace CAPI & Attribution

## App Details

AdTrace Markets & Attribution helps Shopify merchants run accurate tracking across multiple markets, storefront domains, and advertising destinations from one control plane. The app connects Shopify stores to a hosted tracking backend that normalizes ecommerce events, applies merchant-defined event mappings, and routes clean conversion data to supported destinations such as Meta, GA4, Google Ads, and TikTok. Merchants can manage domains, markets, custom event mappings, and delivery diagnostics without relying on separate pixel setups for each storefront.

## Features

1. Multi-market and multi-domain tracking
   Connect one Shopify store to a shared tracking layer that understands storefront domains, market context, currency, and region-specific traffic.

2. Custom event mapping and scenario control
   Map merchant-specific dataLayer or custom checkout events into a consistent ecommerce event model and enable only the scenarios that matter for each store.

3. Destination control by tenant, market, and domain
   Configure Meta, GA4, Google Ads, and TikTok at the store level, then override settings for specific markets or domains when needed.

4. Tracking health and order visibility
   Review captured purchases, delivery outcomes, top products, and order-level tracking status from the control plane instead of checking each destination separately.

5. Support for Shopify and custom checkout flows
   Track Shopify customer events alongside mirrored dataLayer events from custom storefront and checkout implementations.

## Naming Notes

The strongest name should signal three things immediately:

- this is a tracking product
- it is built for cross-market Shopify complexity
- it is broader than a single Meta pixel integration

`AdTrace Markets & Attribution` keeps the positioning focused on merchant outcomes rather than only on Facebook or CAPI terminology.
